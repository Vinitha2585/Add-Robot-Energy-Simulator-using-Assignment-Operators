
# 🤖 Robot Energy Simulator Using Assignment Operators

## 📌 Project Overview
The Robot Energy Simulator is a simple Python project that demonstrates the use of Assignment Operators. It simulates how a robot's energy changes while performing different activities such as walking, lifting, charging, using solar mode, dividing tasks, and calculating backup energy.

## ✨ Features
- Accepts user input for robot energy and activities
- Uses Assignment Operators:
  - `=`
  - `+=`
  - `-=`
  - `*=`
  - `//=`
  - `%=`
- Displays the robot's energy after each operation

## 🛠️ Technologies Used
- Python 3

## 📚 Concepts Used
- Variables
- User Input
- Assignment Operators
- Arithmetic Operations
- Output Formatting
